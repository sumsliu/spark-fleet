# Roadmap

## Available in v0.1 alpha

- DeepSeek TP4 and GLM TP8 parameter profiles with explicit runtime boundaries.
- Read-only inventory, reviewable argv, fresh source/boot/image-bound plans and guarded release supervision.
- Fingerprint-locked historical DeepSeek fixes and GLM native TTL source overlays.
- Bounded API qualification, paired benchmark/drift tooling, weight manifests and network measurement plans.
- Optional receipt-gated mTLS gateway, English/Chinese entry docs and contributor templates.

## Next: independent reproduction

- A complete, pinned, redistributable runtime build recipe for each model, with legal/provenance review and automated image manifests.
- GPU qualification of the portable controller on a fresh four-node and eight-node fleet.
- Synthetic 140K tool-chain/competition fixtures with streamed tool/text timing and verified cache usage.
- Full-window and actual long-output quality/resource testing, not only budget acceptance.
- Per-rail RDMA and all-rank NCCL reports with repeatable node/fabric discovery.

## Then: lower-friction adoption

- Operator-reviewed local client bridge for UIs that cannot provide mTLS certificates.
- Structured per-round/per-rank diagnostics without exposing private prompts.
- Additional runtime versions, topology profiles and client model-inheritance regression fixtures.
- Improved packaging, schema validation and service-manager integration after independent fleet feedback.

No release date or throughput target is guaranteed. The project promotes changes when stable net benefit and correctness are demonstrated. Negative results remain useful project output.
